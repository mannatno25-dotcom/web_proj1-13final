# P6 - Full portfolio page structure in semantic HTML

**Aim:** build the complete skeleton of the portfolio: header/nav, hero, about, skills, projects, experience, contact form, footer.

**Highlights**
- Skip link (`.skip-link`) for keyboard users.
- Each section labelled with `aria-labelledby`; each project is an independent `<article>`.
- Experience as an ordered list with `<time datetime>`.
- Accessible form: `<label for>`, `fieldset`/`legend`, `autocomplete`, `required`.

**Files:** `index.html`, `style.css` (minimal). **Run:** open `index.html`.
