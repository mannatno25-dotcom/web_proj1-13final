Positioning cheat-sheet

ValueStays in flow?Offsets relative toUsed here for
staticYes(offsets ignored)Default for everything
relativeYesIts own normal positionAnchor for absolute children (.card)
absoluteNoNearest positioned ancestorCard badge & overlay
fixedNoThe viewportBack-to-top button
stickyYes (until stuck)Nearest scrolling ancestorNavbar

Extra content so the page is tall enough to scroll and prove the navbar sticks.

Positioned elements can be stacked with z-index. The navbar uses --z-nav (100), the overlay uses --z-overlay (10), so the navbar always stays on top.
