# P5 - Semantic bio page

**Aim:** write a short biography page using semantic HTML5 elements instead of generic `<div>`s.

**Elements used:** `header`, `nav`, `main`, `section`, `aside`, `footer`, `figure`/`figcaption`, `blockquote`/`cite`, `address`, `time`, `abbr`, `dl`/`dt`/`dd`, `ul`/`ol`, heading levels h1-h3 in order.

**Why semantic?** Screen readers and search engines understand the page structure; landmarks let keyboard users jump between regions.

**Files:** `index.html`, `style.css` (light styling only).
**Run:** open `index.html` in a browser.
