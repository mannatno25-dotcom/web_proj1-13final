What makes this grid "advanced"

  • repeat(auto-fit, minmax(min(100%, 16rem), 1fr)) - columns appear and disappear as space allows; no breakpoints for the column count.
  • grid-auto-rows - every implicit row is the same height, so spans line up perfectly.
  • grid-column: span 2 / grid-row: span 2 - tiles of different sizes.
  • grid-auto-flow: dense - small tiles jump back to fill holes left behind.
  • Spans are only applied from 40em up, because a two-column span in a one-column grid would create an extra, unwanted column.
