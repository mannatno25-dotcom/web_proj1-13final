Advanced Flexbox: header & footer

The page is a flex column with min-height: 100vh and main { flex: 1 }, so the footer sits at the bottom of the window even though this page is short.

Where each Flexbox feature is used

PropertyUsed for
justify-content: space-betweenLogo left, nav middle, actions right; copyright left, social right
align-items: centerVertically centres logo, links, search and button
flex: 1 on the navNav absorbs spare space and centres its links
flex-wrap + flex-basis: 100%Nav drops to a second row on small screens
orderMobile: actions move up beside the logo, nav goes below, no HTML change
gapAll spacing between flex items (no margins needed)
margin-top: auto / flex: 1 on mainSticky footer
flex: 2 1 18rem vs flex: 1 1 9remFooter brand column is twice as wide as link columns
