Which one should I use?

Flexbox: one dimension

  • Content decides the size (nav links, buttons, tags)
  • Items sit in a single row or column
  • You need to align or distribute along one axis
  • Components: toolbars, card footers, form rows

Grid: two dimensions

  • Layout decides the size (page shell, galleries)
  • Rows and columns must line up together
  • You want to place items by area or line
  • Page-level structure, dashboards, magazines

Rule of thumb: Grid for the outside (page and sections), Flexbox for the inside (components). They nest happily.
