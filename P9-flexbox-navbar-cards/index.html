How it works

.cards { display: flex; flex-wrap: wrap; gap } and .card { flex: 1 1 18rem } mean: start at 18rem, grow to share leftover space, shrink if needed, wrap when there is no room. The card footer uses margin-top: auto so every "View" button sits at the bottom, even when text lengths differ.
